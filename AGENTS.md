# Agent Guidelines - Workspace Orientation

## Workspace Overview
This project maintains a heirarchy of Project Development guideline documents, templates, and instructions for doing DIY, hobby, or small-scale projects.  This project ONLY maintains the documentation, it does not modify or update any existing documenation for the framework.

## Core Rules & Invariants
- Do not modify any files without specific instructions to do so.
- Ignore local packages and services when deciding what belongs in the project documentation unless there are specific instructions to include them.
- Do not modify files in `/_archive` unless explicitly instructed.
- Keep `AGENTS.md` updated when introducing new top-level directories.
- Write documents and copy to the 10th Grade reading level with an instructional tone, minimize conversational text.
- Feel free to use Mermaid diagrams when it makes sense.
