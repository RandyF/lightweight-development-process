# Agent Guidelines - Workspace Orientation

## Workspace Overview
This folder structure provides a set of rules and documentation framework structures for managing a hobby, DIY, or small project at the very top level.  This ruleset is used for defintion of overall project goals.

## Core Rules & Invariants
- These are REFERENCE documents to be used as a ruleset for other projects, these are not intended to be overall project documents.
- When building task context, only use these rulesets and instructions for creating or evaluating project level functionality.
