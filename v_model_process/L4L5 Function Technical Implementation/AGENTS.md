# Agent Guidelines - Workspace Orientation

## Workspace Overview
This folder structure provides a set of rules and documentation framework structures for lower level parts of a hobby, DIY, or small project component and how that component itself behaves.  Use these rulesets along with the L3 rules for defininig the responsibilites of the component itself.

## Core Rules & Invariants
- These are REFERENCE documents to be used as a ruleset for other projects, these are not intended to be overall project documents.
- When building task context, only use these rulesets and instructions for creating and evaluating functional, technical, and implementation documentation for the project.
