# Agent Guidelines - Workspace Orientation

## Workspace Overview
This folder structure provides a set of rules and documentation framework structures for managing major parts of a hobby, DIY, or small project in their own context.  Use these rulesets along with the L2 rules for defininig the architectural responsibilites for each compoent of the project.

## Core Rules & Invariants
- These are REFERENCE documents to be used as a ruleset for other projects, these are not intended to be overall project documents.
- When building task context, only use these rulesets and instructions for creating and evaluating architectural component responsiblities.
