# Agent Guidelines - Workspace Orientation

## Workspace Overview
This folder structure provides a set of rules and documentation framework structures for breaking a hobby, DIY, or small project into managable components and their responsiblities.  Use these rulesets along with the L1 rules for decomposing project goals into managable components.

## Core Rules & Invariants
- These are REFERENCE documents to be used as a ruleset for other projects, these are not intended to be overall project documents.
- When building task context, only use these rulesets and instructions for creating and evaluating project architecture.
